# project/brainstorms/ — discovery captures

Raw capture files from brainstorm / discovery / grill sessions:
`YYYY-MM-DD-<topic-slug>.md`.

The capture always stays here. A polished deliverable graduates to
`docs/` or `docs/plans/`; a settled decision promotes to
`docs/decisions.md` as an ADR. Nothing here is load-bearing for the
running project — it's the thinking, not the conclusion.
